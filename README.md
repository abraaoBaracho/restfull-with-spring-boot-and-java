🚀 Curso RESTful API com Spring Boot e Java

Este repositório contém meus estudos e práticas no desenvolvimento de APIs RESTful utilizando Java e Spring Boot.

O objetivo deste curso é aprender a construir APIs modernas, seguindo boas práticas, arquitetura limpa e padrões REST.

📚 Conteúdo do Curso

✅ Fundamentos de APIs REST

✅ HTTP (GET, POST, PUT, DELETE)

✅ Estrutura de projeto com Spring Boot

✅ Controllers

✅ Services

✅ Repositories

✅ Integração com Banco de Dados

✅ JPA / Hibernate

✅ Validações

✅ Tratamento de exceções

🔜 Segurança com Spring Security

🔜 Autenticação com JWT

🔜 Documentação com Swagger/OpenAPI

🔜 Deploy da aplicação

🛠️ Tecnologias Utilizadas

Spring Boot

▶️ Como Executar o Projeto
1️⃣ Clonar o repositório
git clone https://github.com/seuusuario/seu-repositorio.git

2️⃣ Entrar na pasta
cd seu-repositorio

3️⃣ Executar o projeto

Se estiver usando Maven:

./mvnw spring-boot:run


Ou execute pela sua IDE (IntelliJ / VSCode / Eclipse).
